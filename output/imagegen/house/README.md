# House page image set

Six original images generated with the built-in image generation tool, then connected to `/house`.

| Original PNG | Chapter | Native pixels |
| --- | --- | --- |
| house-hero.png | Opening bottle portrait on limestone | 1536 × 1024 |
| house-composition.png | Perfumer's bench and raw materials | 1024 × 1536 |
| house-gold-editorial.png | Small gold flakes and faceted glass base | 1024 × 1536 |
| house-cap.png | Engraved gold cap on stone | 1024 × 1536 |
| house-label-editorial.png | Brushed gold front label | 1024 × 1536 |
| house-edition.png | Quiet stone and amber light behind the closing promise | 1536 × 1024 |

The exact prompts, reference paths and provenance are recorded in `prompts.json`.
WebP versions are in `public/media/` with matching filenames.
The four craft photographs display at no more than 512 CSS pixels wide, in their original 2:3 proportions.
The supplied product reference determines the bottle, cap engraving, front label and original small flakes.
